# 🛒 Intelligent Product Recommendation System (Intermediate Level)

## 📌 Project Overview
This project combines Market Basket Analysis and Social Network Analysis (SNA) to build an intelligent product recommendation system. It identifies relationships between products, visualizes them as a network, and provides real-time recommendations using an interactive Streamlit dashboard.

## 🎯 Objectives
- Discover frequently bought product combinations
- Generate association rules using Apriori algorithm
- Visualize product relationships as a network graph
- Recommend products dynamically
- Analyze product popularity

## 🧠 Key Concepts
- Apriori Algorithm
- Association Rule Mining (Support, Confidence, Lift)
- Graph Theory (Nodes, Edges)
- Degree Centrality
- Data Visualization

## ⚙️ Tech Stack
- Python
- Pandas
- MLxtend
- NetworkX
- Matplotlib
- Streamlit

## 🚀 Features
- Product recommendation system
- Product popularity chart
- Network graph visualization (SNA)
- Interactive UI using Streamlit

## ▶️ How to Run
1. Install dependencies:
pip install -r requirements.txt

2. Run Streamlit app:
streamlit run app.py

## 📊 Output
- Frequent itemsets
- Association rules
- Product recommendations
- Network graph
- Popularity chart

## 🎓 Conclusion
This project demonstrates how combining data mining with social network analysis provides deeper insights into customer behavior and improves recommendation systems.
